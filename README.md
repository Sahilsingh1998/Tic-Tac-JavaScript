#Tic-Tac-Toe Game Using JavaScript
This repository contains a simple Tic-Tac-Toe game built with HTML, CSS, and JavaScript. The game allows two players to compete against each other on a 3x3 grid, with the goal of being the first to get three of their marks (either "X" or "O") in a row, either horizontally, vertically, or diagonally.

Features
Two-Player Gameplay: The game allows two players to take turns.

Responsive Design: Fully responsive to be played on desktops, tablets, and mobile devices.

Dynamic Gameboard: Players interact with the gameboard, making moves by clicking on empty squares.

Game Reset: Option to reset the game once it’s over, allowing for a fresh start.

Winner Detection: The game automatically detects when a player wins or when the game is a draw.

Simple and Clean UI: Easy-to-use interface with minimalistic design.
